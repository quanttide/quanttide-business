# quanttide-business
量潮商务拓展

## 概述

量潮商务拓展（quanttide-business）是量潮知识管理体系中的**商务拓展**领域，涵盖合作伙伴关系管理、市场开拓、销售策略与客户关系维护等核心能力。

## 领域边界

- **合作伙伴管理**：合作伙伴筛选、评估、关系维护
- **市场开拓**：目标市场分析、渠道建设、商机挖掘
- **销售策略**：定价策略、合同谈判、成交管理
- **客户关系**：客户信息管理、售前支持、售后维护
